# genpark-seo-audit

## Overview
This skill acts as an on-page and technical SEO consultant. It reviews website copy, provides keyword suggestions, and structures "glossary marketing" content for authority building.

## Capabilities
1. **Content Audit**: Analyze provided HTML or text for heading structure, meta tags compliance, and keyword density.
2. **Keyword Strategy**: Suggest related "long-tail" or low-competition keywords for a given topic.
3. **Glossary Building**: Automatically generate comprehensive definitions for industry terms to drive organic traffic.

## Usage Instructions
When tasked with an SEO review:
- Require the URL or text content target.
- Point out missing H1s, excessive DOM size (if known), or missing alt texts.
- Propose an optimized version of the text including the suggested long-tail keywords.
